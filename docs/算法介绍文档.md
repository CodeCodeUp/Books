### 1. 用户协同过滤算法 (User-Based Collaborative Filtering)

#### 🎯 核心思想
**"找到与你兴趣相似的用户，推荐他们喜欢但你还没读过的图书"**

#### 📚 应用场景
- **位置**: 推荐页面的个性化推荐
- **目标**: 帮助用户发现新的图书类型和作者
- **优势**: 能推荐用户意想不到的优质图书

#### 🧮 数学原理

##### 相似度计算 - 余弦相似度
```
设用户A和用户B对共同评分图书的评分向量分别为：
user_A = [r_A1, r_A2, ..., r_An]
user_B = [r_B1, r_B2, ..., r_Bn]

余弦相似度公式：
similarity(A,B) = cos(θ) = (A·B) / (||A|| × ||B||)

其中：
A·B = Σ(r_Ai × r_Bi)  # 向量点积
||A|| = √(Σ(r_Ai²))   # 向量A的长度
||B|| = √(Σ(r_Bi²))   # 向量B的长度
```

##### 评分预测 - 加权平均
```
预测用户u对图书i的评分：
predicted_rating(u,i) = Σ(similarity(u,v) × rating(v,i)) / Σ|similarity(u,v)|

其中：
v ∈ 与用户u相似且评分过图书i的用户集合
similarity(u,v) ∈ [0,1] 为用户相似度
```

### 2. 物品协同过滤算法 (Item-Based Collaborative Filtering)

#### 🎯 核心思想
**"如果两本图书被用户以相似的方式评分，那么它们就是相似的图书"**

#### 📚 应用场景
- **位置**: 图书详情页的"喜欢这本书的用户也喜欢"
- **目标**: 帮助用户发现与当前图书相似的其他图书
- **优势**: 推荐结果稳定，解释性强

#### 🧮 数学原理

##### 图书相似度计算
```
设图书A和图书B被共同用户的评分向量分别为：
book_A = [r_1A, r_2A, ..., r_nA]  # n个用户对图书A的评分
book_B = [r_1B, r_2B, ..., r_nB]  # 相同n个用户对图书B的评分

图书相似度：
similarity(A,B) = cos(θ) = (A·B) / (||A|| × ||B||)
```

##### 举例说明
```
图书《哈利波特》: [用户1=5分, 用户2=4分, 用户3=5分]
图书《指环王》:   [用户1=5分, 用户2=4分, 用户3=4分]

计算过程：
点积 = 5×5 + 4×4 + 5×4 = 25 + 16 + 20 = 61
||哈利波特|| = √(5² + 4² + 5²) = √66 = 8.12
||指环王|| = √(5² + 4² + 4²) = √57 = 7.55

相似度 = 61 / (8.12 × 7.55) = 61 / 61.31 = 0.995 (高度相似)
```

### 3. 内容特征推荐算法 (Content-Based Filtering)

#### 🎯 核心思想
**"基于图书的内容特征和用户的兴趣特征进行匹配推荐"**

#### 📚 应用场景
- **新用户冷启动**: 没有评分历史时基于用户特征推荐
- **内容相似性**: 图书详情页的内容特征相似图书
- **降级策略**: 协同过滤失败时的备选方案

```python
def recommend_by_user_features(self, user_info, user_id, top_n):
    """
    优先级策略：
    1. 兴趣优先：如果用户选择了兴趣，优先推荐兴趣主题的图书
    2. 年龄辅助：如果用户有年龄信息，作为辅助排序条件
    3. 质量兜底：如果兴趣推荐不足，用高质量图书补充
    """
    # 1. 排除用户已评分的图书（重要：避免数据泄露）
    user_rated_books = get_user_rated_books(user_id)

    # 2. 检查用户兴趣
    user_interests = user_info.get('interests', [])  # 例如: [22, 15, 8]

    if user_interests:
        # 使用兴趣推荐（优先级最高）
        recommendations = recommend_by_interests(user_id, user_interests, user_rated_books, user_info, top_n)

        if len(recommendations) >= top_n:
            return recommendations[:top_n]

        # 兴趣推荐不足，用年龄偏好补充
        if user_info.get('age'):
            age_recs = recommend_by_age(user_id, user_info, user_rated_books, top_n - len(recommendations))
            recommendations.extend(age_recs)
            return recommendations[:top_n]

    elif user_info.get('age'):
        # 只有年龄，使用年龄偏好推荐
        return recommend_by_age(user_id, user_info, user_rated_books, top_n)

    else:
        # 无特征，返回高质量图书
        return get_top_quality_books(user_id, top_n)

def recommend_by_interests(self, user_id, interest_ids, exclude_book_ids, user_info, top_n):
    """
    基于用户兴趣主题推荐图书

    核心逻辑：
    1. 根据 user_interests 中的 theme_id 匹配 books 表的 theme_id
    2. 按评分和评分人数排序
    3. 排除用户已评分的图书
    """
    # 从数据库查询符合兴趣主题的图书
    interest_books = get_books_by_themes(
        theme_ids=interest_ids,
        exclude_book_ids=exclude_book_ids,
        limit=top_n * 2
    )

    recommendations = []
    user_age = user_info.get('age')

    for book in interest_books:
        match_score = 0.7  # 兴趣基础分

        # 年龄偏好加成
        if user_age and book.year:
            age_bonus = calculate_age_preference_score(user_age, book.year)
            match_score += 0.3 * age_bonus

        recommendations.append({
            'bookId': book.book_id,
            'title': book.title,
            'content_score': match_score,
            'algorithm': 'interest_based',
            'reason': '根据您选择的兴趣主题推荐'
        })

    # 按匹配分数排序
    recommendations.sort(key=lambda x: (x['content_score'], x['avgRating']), reverse=True)
    return recommendations[:top_n]
```

##### 基于内容的图书相似度
```python
def calculate_book_content_similarity(self, book1, book2):
    """
    权重分配(总计1.0):
    - 作者相似度: 0.30 (30%)
    - 主题相似度: 0.25 (25%)
    - 出版社相似度: 0.25 (25%)
    - 年份相似度: 0.15 (15%)
    - 评分相似度: 0.05 (5%)
    """
    similarity = 0.0

    # 1. 作者相似度 (30%)
    if book1.author == book2.author and pd.notna(book1.author):
        similarity += 0.30

    # 2. 主题相似度 (25%)
    if pd.notna(book1.get('theme_id')) and pd.notna(book2.get('theme_id')):
        if book1['theme_id'] == book2['theme_id']:
            similarity += 0.25

    # 3. 出版社相似度 (25%)
    if book1.publisher == book2.publisher and pd.notna(book1.publisher):
        similarity += 0.25

    # 4. 年份相似度 (15%)
    if pd.notna(book1.year) and pd.notna(book2.year):
        year_diff = abs(int(book1.year) - int(book2.year))
        year_similarity = max(0, 1 - year_diff / 20)  # 20年内认为相似
        similarity += 0.15 * year_similarity

    # 5. 评分相似度 (5%)
    if pd.notna(book1.avg_rating) and pd.notna(book2.avg_rating):
        rating_diff = abs(float(book1.avg_rating) - float(book2.avg_rating))
        rating_similarity = max(0, 1 - rating_diff / 2)  # 2分内认为相似
        similarity += 0.05 * rating_similarity

    return similarity
```

### 4. 混合推荐策略 (Hybrid Recommendation)

#### 🎯 核心思想
**"智能组合多种推荐算法，取长补短，提供最优推荐结果"**

#### 🔄 混合策略决策树（智能路由）

**个人推荐页面策略**：
```
检查用户状态
├── 有评分历史 + 有兴趣
│   └── 【三层混合推荐】CF + TF-IDF + 兴趣加权 ✨ 核心算法
│       ├── Step 1: 获取协同过滤推荐 (Top 20)
│       ├── Step 2: 获取TF-IDF内容推荐 (Top 20)
│       ├── Step 3: 计算动态混合比例 (CF: 50%-90%, Content: 10%-50%)
│       ├── Step 4: 对匹配兴趣的图书进行加权 (TF-IDF +30%, CF +15%)
│       └── Step 5: 按动态比例混合并返回 Top-N
├── 有评分历史 + 有年龄 (无兴趣)
│   └── 【双层混合推荐】CF + TF-IDF (动态比例)
│       ├── 协同过滤推荐
│       ├── TF-IDF内容推荐
│       └── 动态比例混合 (无兴趣加权)
├── 有评分历史 + 无特征
│   └── 【双层混合推荐】CF + TF-IDF (动态比例)
├── 无评分历史 + 有兴趣
│   └── 【兴趣主题推荐】基于 user_interests 表
│       ├── 匹配 books.theme_id
│       └── 年龄偏好加成
├── 无评分历史 + 有年龄
│   └── 【年龄偏好推荐】基于年龄组偏好
└── 无评分历史 + 无特征
    └── 【优质热门图书】评分≥4.0, 评分人数≥20
```

**图书详情页策略**：
```
检查目标图书数据质量
├── 物品协同 + 内容特征都有结果
│   └── 【动态混合推荐】✨ 核心创新
│       ├── Step 1: 获取物品协同过滤推荐 (Top 12)
│       ├── Step 2: 获取内容特征推荐 (Top 12)
│       ├── Step 3: 计算动态混合比例 (CF: 40%-85%, Content: 15%-60%)
│       ├── 动态比例公式:
│       │   quantity_score = min(rating_count / 100, 1.0)
│       │   cf_quality_score = min(cf_count / 20, 1.0) × cf_avg_similarity
│       │   confidence = quantity_score × cf_quality_score
│       │   cf_ratio = 0.40 + 0.45 × confidence
│       └── Step 4: 按动态比例混合并返回 Top-6
├── 仅物品协同有结果
│   └── 【纯协同过滤】100% CF (item_cf_only)
├── 仅内容特征有结果
│   └── 【纯内容特征】100% Content (content_only)
└── 两者都无结果
    └── 【同作者降级】同作者高评分图书 (same_author_fallback)
```

##### 三层混合推荐（核心创新）✨
```python
def _get_triple_hybrid_recommendations(self, user_id, user_info, top_n):
    """
    三层混合推荐：CF + TF-IDF + 兴趣加权

    核心思想：
    1. 获取协同过滤推荐（CF）
    2. 获取TF-IDF内容推荐（Content）
    3. 动态计算混合比例（基于置信度）
    4. 对兴趣匹配的图书进行加权提升
    5. 按动态比例混合三种推荐源
    """
    # 1. 获取协同过滤推荐
    cf_recommendations = get_cf_recommendations(user_id, top_n * 2)

    # 2. 获取TF-IDF内容特征推荐
    content_recommendations = get_content_based_recommendations(user_id, top_n * 2)

    # 3. 获取用户兴趣主题ID
    user_interests = user_info.get('interests', [])  # [22, 15, 8]

    # 4. 动态计算CF和Content的基础比例
    confidence = (num_similar_users / 50) × avg_similarity
    cf_ratio = 0.5 + 0.4 × confidence  # 范围: [0.5, 0.9]
    content_ratio = 1.0 - cf_ratio     # 范围: [0.1, 0.5]

    # 5. 对推荐结果进行兴趣加权
    for rec in cf_recommendations + content_recommendations:
        book_theme_id = get_book_theme_id(rec['bookId'])

        if book_theme_id in user_interests:
            # 匹配用户兴趣，提升评分
            if 'similarity' in rec:
                rec['similarity'] *= 1.3  # TF-IDF提升30%
            if 'content_score' in rec:
                rec['content_score'] *= 1.3
            if 'predicted_rating' in rec:
                rec['predicted_rating'] *= 1.15  # CF预测评分提升15%

            rec['interest_boosted'] = True
            rec['matched_theme_id'] = book_theme_id

    # 6. 重新排序（按提升后的评分）
    cf_recommendations.sort(key=lambda x: x.get('predicted_rating', 0), reverse=True)
    content_recommendations.sort(key=lambda x: x.get('similarity', 0), reverse=True)

    # 7. 按动态比例混合
    cf_count = int(top_n * cf_ratio)
    content_count = top_n - cf_count

    mixed_result = cf_recommendations[:cf_count] + content_recommendations[:content_count]
    mixed_result = remove_duplicates(mixed_result)

    return mixed_result[:top_n]
```

```python
    基于协同过滤置信度动态计算混合比例

    置信度计算公式：
        confidence = (相似用户数量/50) × 平均相似度
        cf_ratio = 0.5 + 0.4 × confidence  # 映射到[0.5, 0.9]区间

    设计理念：
    - 基准线 50%: 即使置信度为0，协同过滤也占一半权重
    - 最大值 90%: 避免完全依赖协同过滤，保留内容特征的贡献
    - 动态调节: 相似用户越多、相似度越高，CF权重越大
    """
    if not similar_users_data:
        return 0.50, 0.50, {'confidence_score': 0.0}

    # 1. 相似用户数量归一化 [0, 1]
    num_similar_users = len(similar_users_data)
    user_quantity_score = min(num_similar_users / 50.0, 1.0)

    # 2. 平均相似度 [0, 1]
    similarities = [user['similarity'] for user in similar_users_data]
    avg_similarity = np.mean(similarities)

    # 3. 置信度分数 = 数量得分 × 相似度质量
    confidence_score = user_quantity_score * avg_similarity

    # 4. 映射到协同过滤比例
    cf_ratio = 0.50 + 0.40 * confidence_score
    content_ratio = 1.0 - cf_ratio

    return cf_ratio, content_ratio, {
        'confidence_score': confidence_score,
        'num_similar_users': num_similar_users,
        'avg_similarity': avg_similarity,
        'user_rating_count': user_rating_count
    }
```

##### 图书详情页动态混合推荐（数据质量自适应）✨
```python
def get_hybrid_similar_books(self, target_book_id, top_k=6):
    """
    用于图书详情页的相似图书推荐
    根据目标图书的数据质量动态调整混合比例

    策略：
    - 热门书（评分多、相似书多）：协同过滤权重高 (70%-85%)
    - 冷门书（评分少、相似书少）：内容特征权重高 (55%-60%)
    """
    # 1. 获取物品协同过滤推荐
    cf_similar = item_cf.get_similar_books_for_item(target_book_id, top_k * 2)

    # 2. 获取内容特征推荐
    content_similar = content_cf.get_similar_books_by_content(target_book_id, top_k * 2)

    # 3. 动态计算混合比例
    dynamic_cf_ratio, dynamic_content_ratio, confidence_info = \
        _calculate_dynamic_item_ratio(target_book_id, cf_similar, content_similar)

    logger.info(
        f"[图书详情动态比例] 图书ID={target_book_id}: "
        f"评分数={rating_count}, CF={dynamic_cf_ratio:.1%}, "
        f"Content={dynamic_content_ratio:.1%}"
    )

    # 4. 按动态比例混合
    cf_count = int(top_k * dynamic_cf_ratio)
    content_count = top_k - cf_count

    # 5. 去重：移除在协同过滤中已存在的图书
    cf_book_ids = {rec['bookId'] for rec in cf_similar}
    filtered_content = [
        rec for rec in content_similar
        if rec['bookId'] not in cf_book_ids
    ]

    # 6. 组合结果
    mixed_result = []
    mixed_result.extend(cf_similar[:cf_count])
    mixed_result.extend(filtered_content[:content_count])

    # 7. 添加元数据
    for rec in mixed_result:
        rec['mixing_strategy'] = 'dynamic_item_cf_content'
        rec['cf_ratio'] = round(dynamic_cf_ratio, 2)
        rec['confidence_info'] = confidence_info

    return mixed_result[:top_k]

def _calculate_dynamic_item_ratio(self, target_book_id, cf_similar_books, content_similar_books):
    """
    基于图书数据质量动态计算混合比例

    公式：
        quantity_score = min(rating_count / 100, 1.0)
        cf_quality_score = min(cf_count / 20, 1.0) × cf_avg_similarity
        confidence = quantity_score × cf_quality_score
        cf_ratio = 0.40 + 0.45 × confidence  # 范围 [40%, 85%]

    参数说明：
    - rating_count / 100: 100个评分为满分（基于数据分布优化）
    - cf_count / 20: 20本相似书为满分
    - 基准线40%: 即使是极冷门书也给CF保留40%机会
    - 最大值85%: 即使是超热门书也给Content保留15%多样性
    """
    # 获取图书评分统计
    rating_count = get_book_rating_count(target_book_id)

    # 评分数量得分 [0, 1]
    quantity_score = min(rating_count / 100.0, 1.0)

    # 协同过滤质量得分
    if cf_similar_books:
        cf_count = len(cf_similar_books)
        cf_count_score = min(cf_count / 20.0, 1.0)
        cf_avg_similarity = np.mean([book['similarity'] for book in cf_similar_books])
        cf_quality_score = cf_count_score * cf_avg_similarity
    else:
        cf_quality_score = 0.0

    # 综合置信度
    confidence_score = quantity_score * cf_quality_score

    # 映射到CF比例
    MIN_CF_RATIO = 0.40
    MAX_CF_RATIO = 0.85
    cf_ratio = MIN_CF_RATIO + (MAX_CF_RATIO - MIN_CF_RATIO) * confidence_score
    content_ratio = 1.0 - cf_ratio

    return cf_ratio, content_ratio, {
        'rating_count': rating_count,
        'quantity_score': round(quantity_score, 3),
        'cf_quality_score': round(cf_quality_score, 3),
        'confidence_score': round(confidence_score, 3),
        'strategy': 'item_quality_adaptive'
    }

# 示例对比：
# 超热门书（5000评分）: CF 78% + Content 22%
# 热门书（800评分）:    CF 68% + Content 32%
# 中等热度（150评分）:  CF 45% + Content 55%
# 冷门书（8评分）:      CF 40% + Content 60%
```

## 💡 算法创新点

### 1. 统一的动态混合框架 ✨
**问题**: 传统推荐系统使用固定比例混合（如7:3），无法根据数据质量自适应调整

**解决方案**:
- **个人推荐页**: 基于用户协同过滤置信度动态调整（CF 50%-90%）
  - 相似用户越多、相似度越高 → CF权重越大
  - 保证即使置信度低，CF也有50%基础权重
- **图书详情页**: 基于图书数据质量动态调整（CF 40%-85%）
  - 评分数越多、相似图书越多 → CF权重越大
  - 冷门书内容特征占主导，热门书协同过滤更可靠

**效果**:
- 统一的自适应框架，适用于不同推荐场景
- 论文价值高，创新性强
- 推荐质量提升，覆盖冷门到热门全场景

### 2. 图书数据质量自适应 ✨ 新增
**问题**: 冷门书评分少时，固定70%协同过滤权重不合理

**解决方案**: 动态调整协同过滤和内容特征比例
- **极冷门书** (<10评分): CF 40%, Content 60%
- **冷门书** (~50评分): CF 45%, Content 55%
- **中等热度** (~100评分): CF 50%, Content 50%
- **热门书** (~500评分): CF 70%, Content 30%
- **超热门书** (>1000评分): CF 78%+, Content 22%-

**核心公式**:
```
quantity_score = min(rating_count / 100, 1.0)
cf_quality_score = min(cf_count / 20, 1.0) × cf_avg_similarity
confidence = quantity_score × cf_quality_score
cf_ratio = 0.40 + 0.45 × confidence  # [40%, 85%]
```

**效果**:
- 冷门书推荐更准确（依赖内容特征）
- 热门书挖掘更深入（协同过滤权重高）
- 自动平衡数据稀疏性问题
