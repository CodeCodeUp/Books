## 数据库表结构

### 1. 用户表 (users)
```sql
CREATE TABLE `users` (
  `user_id` int NOT NULL AUTO_INCREMENT COMMENT '用户ID',
  `username` varchar(50) NOT NULL COMMENT '登录用户名',
  `password` varchar(255) NOT NULL COMMENT '加密密码',
  `nickname` varchar(50) DEFAULT NULL COMMENT '昵称',
  `age` int DEFAULT NULL COMMENT '年龄',
  `age_group` varchar(20) DEFAULT NULL COMMENT '年龄分组',
  `avatar_url` varchar(500) DEFAULT NULL COMMENT '头像URL',
  `status` tinyint DEFAULT '1' COMMENT '用户状态（1:正常 0:禁用）',
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `last_login_at` timestamp NULL DEFAULT NULL COMMENT '最后登录时间',
  PRIMARY KEY (`user_id`),
  UNIQUE KEY `username` (`username`),
  KEY `idx_username` (`username`),
  KEY `idx_age_group` (`age_group`),
  KEY `idx_status` (`status`)
) ENGINE=InnoDB AUTO_INCREMENT=278857 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='用户表';
```

**注意**: 已移除 `email`, `location`, `country` 字段，简化用户注册流程

### 2. 图书表 (books)
```sql
CREATE TABLE `books` (
  `book_id` varchar(20) NOT NULL COMMENT '图书ID(ISBN)',
  `title` varchar(500) NOT NULL COMMENT '图书标题',
  `author` varchar(200) DEFAULT NULL COMMENT '作者',
  `publisher` varchar(200) DEFAULT NULL COMMENT '出版社',
  `year` int DEFAULT NULL COMMENT '出版年份',
  `theme_id` int DEFAULT NULL COMMENT '图书主题分类ID',
  `image_url_s` varchar(500) DEFAULT NULL COMMENT '小图片URL',
  `image_url_m` varchar(500) DEFAULT NULL COMMENT '中图片URL',
  `image_url_l` varchar(500) DEFAULT NULL COMMENT '大图片URL',
  `avg_rating` decimal(3,2) DEFAULT '0.00' COMMENT '平均评分',
  `rating_count` int DEFAULT '0' COMMENT '评分数量',
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`book_id`),
  KEY `idx_author` (`author`),
  KEY `idx_year` (`year`),
  KEY `idx_theme_id` (`theme_id`),
  KEY `idx_avg_rating` (`avg_rating`),
  KEY `idx_title` (`title`(100)),
  KEY `idx_rate` (`rating_count`) USING BTREE,
  KEY `idx_created_at` (`created_at`) USING BTREE,
  FULLTEXT KEY `idx_search` (`title`,`author`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='图书信息表';
```

**注意**: 新增 `theme_id` 字段用于图书主题分类，关联到 `book_theme` 表

### 3. 评分表 (ratings)
```sql
CREATE TABLE `ratings` (
  `rating_id` bigint NOT NULL AUTO_INCREMENT,
  `user_id` int NOT NULL COMMENT '用户ID',
  `book_id` varchar(20) NOT NULL COMMENT '图书ID',
  `rating` decimal(2,1) NOT NULL COMMENT '评分(1.0-5.0)',
  `rating_date` timestamp NULL DEFAULT CURRENT_TIMESTAMP COMMENT '评分时间',
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`rating_id`),
  UNIQUE KEY `uk_user_book` (`user_id`,`book_id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_book_id` (`book_id`),
  KEY `idx_rating` (`rating`),
  KEY `idx_rating_date` (`rating_date`),
  KEY `idx_time` (`created_at`) USING BTREE
) ENGINE=InnoDB AUTO_INCREMENT=1301025 DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='用户评分表';
```

### 4. 图书主题表 (book_theme)
```sql
CREATE TABLE `book_theme` (
  `theme_id` int NOT NULL AUTO_INCREMENT COMMENT '主题ID',
  `theme_name_en` varchar(100) NOT NULL COMMENT '主题英文名称',
  `theme_name_zh` varchar(100) NOT NULL COMMENT '主题中文名称',
  `description` varchar(500) DEFAULT NULL COMMENT '主题描述',
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `updated_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`theme_id`),
  UNIQUE KEY `uk_theme_name_en` (`theme_name_en`),
  KEY `idx_theme_name_zh` (`theme_name_zh`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='图书主题分类表';
```

**主题数据**: 包含31个图书主题分类，如 Literature(文学)、Science Fiction(科幻)、Fantasy(奇幻)、Mystery(悬疑)、Romance(浪漫)等

### 5. 用户兴趣表 (user_interests)
```sql
CREATE TABLE `user_interests` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '记录ID',
  `user_id` int NOT NULL COMMENT '用户ID',
  `theme_id` int NOT NULL COMMENT '兴趣主题ID',
  `created_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_theme` (`user_id`, `theme_id`),
  KEY `idx_user_id` (`user_id`),
  KEY `idx_theme_id` (`theme_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci COMMENT='用户阅读兴趣表';
```

**功能说明**: 记录用户选择的阅读兴趣主题，用于个性化推荐和用户画像构建

## 数据库关系设计

### 核心关系
- `users` ↔ `user_interests` ↔ `book_theme`: 用户与兴趣主题的多对多关系
- `books` → `book_theme`: 图书与主题的多对一关系
- `users` ↔ `ratings` ↔ `books`: 用户评分关系
- `users` ← `user_interests` → `book_theme` → `books`: 基于兴趣的推荐路径
